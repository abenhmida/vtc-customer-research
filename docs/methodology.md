# Méthodologie

Le questionnaire cherche à mesurer les comportements réels : acquisition, clientèle directe, outils, agenda, CRM, réactivation, frustrations et disposition à payer.

Ne pas demander seulement « quelles fonctionnalités voulez-vous ? ». Chercher plutôt : comportement actuel → outil → friction → impact → besoin.

Une réponse individuelle est un signal qualitatif, pas une validation statistique.
